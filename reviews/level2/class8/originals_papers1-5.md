# Review — original AMO Level-2 "Extra Mock" papers, Class 8, Tests 01–05

Source: `clean/AMO_L2_Extra_Mock_Class8_Test0{1..5}_QP.pdf` and the matching `_AK.pdf` files.
Method: I rendered every QP page at 110 dpi and extracted the text with `pdftotext -layout`. I solved all 150 questions before opening any key, then compared my answers with the keys. I looked at every figure: P1 Q13 has an embedded raster image (extracted at full resolution). The Q28 rings and the P4 Q13 label are vector drawings, which I zoomed to 250 dpi where needed.

**AK ↔ QP match:** all five keys belong to their papers. Every key title reads "Practice Paper N", the same as its QP header, and the numbers in every worked solution match the QP data. One cosmetic point: the file names say "Extra Mock Test0N" but both documents are headed "Practice Paper N".

Legend: Verdict = OK / WRONG KEY / NO CORRECT OPTION / TWO ANSWERS / FIGURE PROBLEM. Difficulty: E/M/H (H = 3+ real steps or genuine insight). "Apt." means a generic quantitative-aptitude topic (trains, work/pipes, circular tracks, alligation, number series). These topics are not named in AMO v5.9 Class 8 but can be tolerated as "mixed word problems".

## Template reuse

All five papers are clones of one 30-slot template. Each slot keeps the same question type in every paper, with only the numbers changed:

Q1 train; Q2 fractions + remainder; Q3 x±1/x or a+b/ab identity; Q4 ratio after % changes; Q5 CI−SI (2 yr); Q6 recurring decimal; Q7 consecutive numbers average/sum; Q8 combined ratio A:B:C; Q9 "gift packs" floor(budget/pack cost); Q10 Euler's formula; Q11 divisibility of consecutive products / AP sum; Q12 circular track; Q13 polygon–circle ratio (inscribed/circumscribed); Q14 trapezium area/height; Q15 investment-return equation; Q16 two-item price system; Q17 consecutive integers sum; Q18 exponential equation; Q19 flat fee + per-unit charge; Q20 linear equation; Q21 mixture/alligation; Q22 rates (machines/taps/cars); Q23 quadratic number series; Q24 cuboid/cube/cylinder TSA; Q25 factorise and cancel, then evaluate; Q26 CI with year-varying rates; Q27 work; Q28 **ring-walkway area (same figure; key is C in all 5 papers)**; Q29 two shapes with equal perimeter; Q30 identity evaluation.

The Q28 figure is the same ring drawing with "pond r = … / walkway … wide" labels, even where the text says fountain/path. Q1's key is D in 4 of 5 papers. Answer letters are otherwise reasonably balanced (A 7–8, B 5–7, C 8–10, D 7 per paper).
