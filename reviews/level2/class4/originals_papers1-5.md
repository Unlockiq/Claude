# Review — original AMO Class-4 Level-2 Practice Papers 1–5 (150 MCQs)

Sources: `c4/clean/Test0N_QP.pdf` and `c4/in/Test0N_AK.pdf`. I solved every question before reading the key. Every figure was checked at 200 dpi: P3 Q10 and Q26, P4 Q14 and Q26, and P5 Q10 and Q26. No other question has a picture. My renders are in `c4/review_a/`.

## Summary

**Wrong keys (1)**
- **P1 Q30**: the radius is 3 m, so the circumference is 2×22/7×3 = 132/7 ≈ 18.86 m. The total is 64 + 18.86 = **82 6/7 m**, which is not among the options. The key gives C (108). Its solution uses r = **7** (2×22/7×7 = 44). The question is broken and the solution does not match the stem.

**Broken / ambiguous (5)**
- **P1 Q4** (21, 49, 56, 65): 65 is the only number that is not a multiple of 7 (key D). But 56 is the only even number, so C is equally defensible.
- **P3 Q4** (234, 432, 824, 711): 824 has a different digit-sum (key C). But 711 is the only odd number, so D is also valid.
- **P3 Q26**: the figure puts both the 70° label and the x label in the same region, to the right of the right ray. The drawn rays measure about 50° and 70° from the line. The angle between the rays (the intended x = 60°) has no label. Read as drawn, x = 70° (option C). The key is B.
- **P5 Q3**: 2 1/4 + 1 3/4 = 4 (key C), but option D "3 4/4" also equals 4 in value. It is non-standard notation, so two options have the same value.
- **P1 Q30**: there is no correct option (see above).

**Solution text / figure defects (beyond the above)**
- P5 Q26: the figure is not to scale and says nothing about this. The drawn angles are about 49°/127°/67°/**116°** against labels of 80/110/95/y = 75. The angle y is drawn obtuse, but the answer is acute.
- P3 Q10: there are two overlapping "3 cm" labels and the top width has no label. The figure can still be solved, and 18 is correct.
- P4 Q3: the solution relies on HCF, which is Class 5.
- P5 Q27: the solution divides by 0.8, which is decimal division.
- P4 Q18: the reasoning "any digit × 0 = 0" is sloppy (it should be 0 × 100 = 0).
- P2 Q19: the solution has stray "✓" glyphs.
- P2 Q3: the options are laid out in A/C/B/D order (cosmetic).
