# Review of the original AMO L2 Class 1 practice papers 6–10 (150 MCQs)

I solved every question from the question-paper pictures first (with the website watermark removed), then compared it with the answer key. Close counts were checked at 300 dpi. Greyscale checks used luminance Y = 0.299R + 0.587G + 0.114B, measured on pixels.

## Summary

**Wrong key letters (2)**
- **P7 Q19.** The key says C (14), from "Staircase has 7 steps". The picture has **6 steps**: 6 treads and 6 risers, checked at 300 dpi and against the watermarked original. 6 + 6 = 12, so the answer is **A**.
- **P8 Q16.** The key says B (7), counting "BUTTONS(2)". BUTTONS has only one B. B-count = BUNNY 1 + BOUGHT 1 + BIG 1 + BOXES 1 + BLUE 1 + BUTTONS 1 = **6**, so the answer is **A**.

**Broken questions (4 hard-broken, plus 4 that fail in greyscale or are ambiguous)**
- **P6 Q16.** It asks how many times 'T' appears. The true count is **10**: TINA 1, THE 1, TURTLE 2, TOOK 1, TWO 1, TASTY 2, TARTS 2. The options are 6/7/8/5, so no option is correct. The key's 7 counts only the first letter of each word.
- **P10 Q29.** It asks how many more triangles are in the bottom section than in the top. The picture has **top = 14** (7+7) and **bottom = 5**, so the bottom has *fewer* and the premise is false. The key gets 9 only by swapping the sections ("Bottom: 14, Top: 5").
- **P6 Q21, P8 Q21, P10 Q21.** In these odd-group-of-balls questions, the two colours are almost the same in greyscale: red Y≈108 vs blue Y≈115 (P6), green 122 vs red 108 (P8), pink 122 vs teal 126 (P10). On a B/W printout all 4 groups look the same.
- **P8 Q20.** This is a colour-sequence pattern. Option B (4 green balls) also fits the count pattern 1, 2, 3, 4, so only colour separates A from B.
- **Ambiguous / quality problems:**
  - P10 Q19: the realistic staircase's top tread could be read as a landing, giving 5 steps and 15 (= B). The key says 6 steps.
  - P10 Q20: there is **no question text**, only the picture.

**Solution text wrong or mismatching the picture (9)**
- P6 Q10: garbled text, "D: 50=60? No — 6 tens = 60, not 50".
- P6 Q16: only first letters counted.
- P6 Q30: the key says P=3, Q=6, S=4. The picture shows P=1, Q=2, S=3; R=5 is right.
- P7 Q19: says 7 steps; there are 6.
- P8 Q5: says "5+5+1"; the picture rows are 4+4+3 (total 11 is right).
- P8 Q16: says BUTTONS(2).
- P10 Q6: says "3 grapes"; they are 3 grape *bunches*.
- P10 Q29: top and bottom swapped.
- Throughout: solutions use "×" facts (12×2, 6×4, 8×3, 5×6, 3×6, 7×2, 5×4 …). This is not Class 1 equal-groups language.
