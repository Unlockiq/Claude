# AMO Class 1 Level-2: review of original Practice Papers 1–5

Scope: Test01–Test05 QP (clean) checked against Test01–Test05 AK. Every question was solved from the picture first, then compared with the key. Close counts were zoomed at 200 dpi. Bouquet colours were also counted by machine (yellow-centre detection plus petal-hue classification).

### Structural note

All five papers use the same template: each Qn is the same question type in every paper, with a new skin. So every syllabus problem appears five times. The colour, queue, letter-count, cap/crown, ribbon and ball-size slots (Q3, Q16, Q21, Q22, Q25, Q26) need replacing in all papers.
