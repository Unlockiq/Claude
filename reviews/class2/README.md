# AMO Level 1 — Class 2 Practice Papers 1–5: Review Summary

Files reviewed: `AMO_C2_L1_PracticePaper{1..5}_v2` (PDF and DOCX). For each paper, every question was solved independently and every picture was recounted. Each question was then checked against the **AMO Vertical Syllabus v5.9 (locked)**: chapter topics, the arithmetic ceiling, the blueprint, and the visual and language standards. The details for each paper are in `paper1.md` … `paper5.md`, and the number-line and colour check is in `../syllabus_visual_rules.md`.

## Overall verdict

The papers are well made. **All 225 keyed answers are correct**, and every question has exactly one correct option. Only 2 questions are broken (Paper 3 Q40 and Paper 4 Q13), and both are fixed in v3 by changing the wording alone.

All 5 papers meet the blueprint exactly:
- **Chapter split:** Ch1 10, Ch2 10, Ch5 7, Ch9 7, Ch10 6.
- **Section I difficulty:** 24 Easy and 16 Medium.
- **Section II pairs:** Q41 Ch1+Ch10, Q42 Ch2+Ch10, Q43 Ch5+Ch10, Q44 Ch1+Ch9, Q45 Ch5+Ch9.
- **Arithmetic ceiling:** numbers up to 999; multiplication only within the tables 1–10; division only as halving or quartering; clock times only o'clock, half past, quarter past and quarter to.

## Must fix (all fixed in v3)
1. **P3 Q40:** "A long rectangle is **cut** into 3 boxes… How many rectangles…?" Cut pieces are separate, so a careful child answers 3, which is option A, but the key says 6. Now: *"A long rectangle is divided into 3 boxes by 2 lines, as in the picture. How many rectangles can you find in all? Count big and small ones."*
2. **P4 Q13:** each cherry picture shows a *pair* of cherries (the same problem as Class 1 P4 Q14). The question now counts "bunches of cherries", and the stem no longer starts with "5 plates…".
3. **Text names objects that aren't drawn:** P5 Q5 (floor tiles), P5 Q9 (planes) and P1 Q28 (school bus). The wording now matches the picture.
4. **Answer key:**
   - The answer cells for P1 Q22, P2 Q43 and P4 Q24 showed only the letter.
   - The P1 Q41 solution left out the 8 ones ("30 tens: 308").
   - The P2 Q40, Q17 and Q19 solutions listed the other options out of order.

## Language (fixed in v3)
- **Sentences starting with a numeral:** P1 Q14; P3 Q4 (all four options) and Q18; P4 Q13 and Q17; P5 Q7, Q14, Q17 and Q18. Many solution sentences are fixed too.
- **Hard or unclear words:**
  - "latest" (P1 Q32), "earlier" (P2 Q34), "fewest" (P3 Q24)
  - "times sum" (P3 Q14), "fast asleep" (P2 Q28), "sapling" (P4 Q36)
  - "Every two friends" (P4 Q40), "written in figures" (P4 Q5), "that is, how many full trays" (P4 Q9)
  - "gives as few notes" (P2 Q44), "Laid apart on a table" (P3 Q45), "then, in all" (P5 Q44)
- **Vague:**
  - "a later tile" (P2 Q42) and "comes later" (P3 Q39)
  - "both of them say" (P2 Q41) and "hop together" (P5 Q41)
  - P1 Q17 never said what the numbers on the baskets mean.
- **Fragment:** P1 Q42 ended with "7 → ?". It now reads: "What does this rule give for 7?"

## Agent suggestions I did not apply (they conflict with the syllabus)
- **P1 Q42 (7 × 7 = 49):** one reviewer called this "beyond Class 2". It isn't: the ceiling allows 1-digit × 1-digit, tables 1–10. The numbers are unchanged; only the wording is fixed.
- **Removing ÷ from solutions:** the Language standard allows ÷ for Classes 1–6, and Class 2 includes "division as sharing". The ÷ signs are kept.
- **The "drawn to scale" line:** this is required by Visual Standards rule 1, so it is kept.

## Still not compliant (needs a redrawn picture or a decision)
- **Number lines (Visual Standards rule 9):** every tick must have a number except the one being asked about.
  - P1 Q8: 330 and 390 have no number.
  - P2 Q3: four ticks are lettered A–D instead of numbered.
  - P5 Q41: only every second tick is numbered.
  - P1 Q29 (the one-day time line) has no arrows. It is borderline.
- **Cover line "Print or view this paper in colour":** this clashes with rule 12(c), which says papers must work in greyscale. No question depends on colour alone. P3 Q37's green and yellow squares look alike in greyscale but can still be counted.
- **Cosmetic picture fixes:**
  - Clock hands run over the numbers: P2 Q30, Q31; P3 Q29; P5 Q32.
  - The cylinder fill stops short at the base: P2 Q21, Q23, Q27, Q45.
  - P4 Q25's fold line A is only slightly off-centre.
  - P5 Q15's wall looks like a bench.
- **Content choices (yours to decide):**
  - Roll/slide questions about solids appear in almost every paper (P1 Q27, P2 Q27, P3 Q27, P4 Q24 + Q27).
  - "Number rule" questions repeat (P1 Q42, P2 Q37, P3 Q36, P4 Q39 + Q41, P5 Q37 + Q42). They fit "mathematical analogies", but there are a lot of them.
  - P4 Q45 is labelled Hard but is easy. P2 Q36 could be Medium.
  - A few wrong options are weak: P5 Q29, Q35 and Q5.
- **Syllabus note:** P3 Q32, P4 Q27, Q36 and Q44 present information in tables. Data handling (Ch8) starts in Class 4, but a table used only to give information is probably fine.
