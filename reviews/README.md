# AMO Level 1 Practice Papers — Classes 1–11: Overall Review

There are 55 papers (5 per class, 2,475 questions). Every question was solved independently, every picture was checked, and every paper was checked against the **AMO Vertical Syllabus v5.9 (locked)**. Each class folder has a summary (`README.md`) and question-by-question notes (`paper1.md` … `paper5.md`).

## Headline results
- **All 2,475 keyed answers are correct.**
- **Every paper meets its blueprint:** chapter counts, 24 Easy + 16 Medium in Section I, and the Section II chapter pairs. This was checked by script (`tools/blueprint_check.py`) before and after fixing.
- **Every fixed paper keeps its page count.** Questions stay on the same page as before, with a handful of noted exceptions where a question moved with its picture.
- **877 question, option and solution fixes were applied, plus 1–2 cover fixes per paper.** None changes a picture or an answer letter, except where a question was broken; those are listed in each class summary.

## Corrections to earlier advice (from the syllabus)
- The "All figures are not necessarily drawn to scale unless stated" line is **required** (Visual Standards rule 1). It is kept in every paper.
- "Odd one out" is a named Class 1 topic, so the phrase is allowed.
- The star questions (Q41–Q45) follow a fixed chapter-pair layout by design.
- Any difficulty relabel must be a swap, because each paper needs exactly 24 Easy and 16 Medium.

## Template issues that affect every class
- **"Print or view this paper in colour"** conflicts with rule 12(c), which says papers must work in greyscale. Only one question (C11 P5 Q31) actually relied on colour, and it is fixed.
- The cover note telling adults to detach the answer sheet as well as the key is fixed in every class.
- **Answer sheets:** bubbles in rows 10–15 are out of line in many papers. This is cosmetic.
- **Class 11 symbols:** z̄ prints as "ź", and a raised ⁿ prints as a quote mark, when inside equation objects. Fix these by hand.
